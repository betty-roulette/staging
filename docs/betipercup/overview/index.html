大会名称

べちぱーCup Vol.1

大会の目的・概要

「べちぱーCup Vol.1」は、Dead by Daylightをみんなで楽しむことを目的とした大会です。参加する方には、普段とは少し違った緊張感や対戦の楽しさを、応援・視聴する方には、それぞれの試合やプレイヤーの活躍を楽しんでいただける大会を目指します。大会のルールやスケジュール、参加者情報などについては、各案内ページをご確認ください。

大会形式

「べちぱーCup Vol.1」は、チームで勝利を目指すDead by Daylightのカスタムマッチ大会です。大会はトーナメント形式で進行し、各試合で使用するキラーはルーレットによって決定します。どのキラーが選ばれるか分からない中で、その場に応じた判断やチームワークが求められる、予測不能な展開も楽しめる大会です。

開催日時

2026年12月19日（土）18:00開始予定（チーム数により変動）
