項目内容
使用パーク
  • 上記の「使用指定パーク」から２つを使用すること
  • １つのパークを２人以上で使用する事は禁止
残り２パーク
  • 残り２つは禁止パーク以外を使用可能
  • １つのパークを２人以上で使用する事は禁止
同一パークの重複
  • チーム内でのパーク重複は禁止

  • アイテムの持ち込みは禁止
