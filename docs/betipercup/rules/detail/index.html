大会ルール詳細

試合の進行

各チームがキラー側・サバイバー側の両方を担当する。

得点集計

  • サバイバー：発電した台数＋脱出
  • キラー：吊り数＋全滅（2ポイント）

勝敗判定

サバイバー＋キラーのポイントが多いチーム。

同ポイント時の優先順位

サバのリザルト２位のBPスコア上位が勝利。

マップ

キラーが以下から選択する。

  1. ①ギデオン食肉工場：ザ・ゲーム
  2. ②壊滅したボルゴ：忘れ去られた遺跡
  3. ③マクミラン・エステート：コールタワー
  4. ④オートヘイヴン国立研究所：地下施設
  5. ⑤スプリングウッド：バダム幼稚園Ⅱ（ボーナスマップ）

試合結果の報告

キラー担当はマッチのリザルト画面のスクリーンショットを運営に提出する。

ボイスチャット

同一チーム内でのVCはOKです。大会側で専用チャンネルを準備します。

共通禁止事項

  • オファリング
  • 煽り行為、ゴースティング
  • チーム外からの試合中の助言・情報提供
  • グリッチ・バグを利用した行為
  • 故意による切断、試合放棄行為

「降参」「儀式を終了」は認めない。ただし運営側から指示があった場合は指示に従うこと。

不慮の切断などによる再試合

  • 5分未満の切断は再試合。
  • 5分以上なら、吊り数・発電数・脱出数でポイント計算。

チームメンバー不揃い

試合開始までにメンバーが揃わなかった場合は棄権とする。試合開始直前でのメンバー交代は運営へ申告し判断を仰ぐ。

大会ルール変更

期間の定めなく、ルール変更は運営側で協議する。協議結果は以下のいずれかで通知とする。

  • サイト上で公開しているルールを修正
  • 大会当日の配信画面にて提示

その他

質問や申告などは「問合せフォーム」よりお願いいたします。

＋違反行為とペナルティ（まとめ）

煽り行為

連続屈伸、不要なライトの連続クリック・使用、特に脱出ゲート付近での行為、ケバブ等の行為は違反とする。

ゴースティング

対戦中に配信・観戦等から対戦相手の情報を取得する行為は違反とする。

チーム外からの助言

試合中にチーム外の人物から助言・情報提供を受ける行為は違反とする。

ゲームから抜ける行為

  • 「降参」及び「儀式を終了」を参加者の判断で実施する事は違反とする。
  • 故意の切断は違反とする。
  • 意図的な試合放棄は違反とする。
  • サバイバーの場合：カラスが３羽ついたら違反とする（ゲームに参加していないと見なす）。
  • キラーの場合：試合に参加する意思が感じられない状況が１分以上続いた場合に違反とする。

キラーの使用とパーク

  • ルーレットによって決まったTierに属さないキラーを使用した場合は違反とする。
  • 禁止パークの使用は違反とする。

サバイバーパーク構成

  • 指定された2パークを使用するルールが決定済みのため、それに従わない場合は違反とする。
  • チーム内でのパーク重複も違反とする。

アイテムとチェスト

  • アイテムの持ち込み及び使用は違反とする。
  • チェストの開放はOKだが、アイテムを拾う・使う行為は違反とする。

オファリングの使用

オファリングはサバイバー、キラーの双方とも使用した場合は違反とする。

ペナルティ

実況・解説者に煽り等の違反行為について判断を一任いたします。明らかな煽り行為であれば、その場で失格とする。判断がつかない場合は警告とする。また、運営が観戦者モードで監視して発覚した違反は、運営内で協議し実況・解説者へ伝えられ、試合中もしくは試合結果発表の前に公表される。

ペナルティ：警告

警告を受けた場合は、マイナス1ポイントとする。試合開始後にパーク・アイテム・アドオン・オファリングなどの違反が見つかった場合は再試合とする。違反項目は1項目につき1ポイントマイナスする。重複の場合はマイナス2ポイント。

ペナルティ：失格

煽り行為、意図的な切断・試合放棄、サバイバー：カラスが３羽ついた、キラー：試合に参加する意思が感じられない状況が１分以上続いた、の行為については発覚次第、失格とする。また、同じ人が2回警告を受けた場合、チームとして失格とする。
